# Medium Java Tasks

A collection of medium-level Java programming problems focused on
improving logic building, problem solving, loops, number manipulation,
and algorithmic thinking.

## Topics Covered

### Number & Mathematical Problems
- Sum of Natural Numbers
- Sum of Squares
- Sum of Cubes
- Factorial-Based Problems
- HCF and LCM
- Prime Number Problems
- Perfect Number Problems
- Armstrong Number Problems
- Strong Number Problems

### Number Manipulation
- Reverse Number
- Palindrome Number
- Digit Frequency
- Digit-Based Calculations
- Number Range Problems

### Number Systems
- Decimal to Binary
- Binary to Decimal
- Decimal to Octal
- Decimal to Hexadecimal

### Series & Patterns
- Fibonacci Series
- Number Series
- Number Pattern Problems

## Learning Approach

**Understand → Analyze → Design Logic → Dry Run → Code → Test → Debug → Refine**

The focus is on developing the ability to solve problems independently
rather than memorizing solutions.
