# Java Projects

A collection of practical Java tasks and projects built to strengthen
problem-solving skills, object-oriented programming, and application development.

## Purpose

This repository contains projects developed while progressing from
Core Java and OOP to database connectivity and backend development.

The focus is on applying concepts to build working applications rather
than only practicing isolated code examples.

## Project Areas

### 01 — Core Java

Projects and tasks based on:

- Variables and data types
- Input and output
- Conditions
- Loops
- Methods
- Number programming
- Problem solving
- Exception handling
- Collections

### 02 — Object-Oriented Programming

Projects focused on:

- Classes and objects
- Encapsulation
- Constructors
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Method overloading and overriding

### 03 — JDBC

Projects involving Java database connectivity:

- JDBC connection
- SQL queries
- CRUD operations
- PreparedStatement
- ResultSet
- DAO pattern
- MySQL integration

### 04 — Hibernate

Projects focused on:

- ORM concepts
- Entities
- Hibernate configuration
- CRUD operations
- Relationships
- HQL / JPQL
- MySQL integration

### 05 — Spring Boot

Projects involving:

- Spring Boot
- REST APIs
- Controllers
- Services
- Repositories
- Spring Data JPA
- Hibernate
- MySQL
- Exception handling
- API development

## Project Levels

Projects are organized according to their complexity.

### Small Tasks

Focused implementations designed to practice a specific concept
or solve a small programming problem.

### Medium Tasks

Tasks that combine multiple concepts and require more structured
problem solving.

### Big Tasks

Larger feature-oriented implementations involving multiple concepts
and components.

### Small Projects

Small working applications built around a focused requirement.

### Medium Projects

Applications combining multiple features and concepts.

### Big Projects

Larger applications involving multiple modules, proper structure,
database integration, and real-world development practices.
